Worker packaging inspection identified native architecture dependencies that must be resolved before the x86 host can run all modules: `apps/video/runtime.py` and `scripts/prepare-video-bundle.py` hard-code `aarch64-linux-gnu`; the video and document archive manifests pin ARM64 packages; `apps/ingestion/Dockerfile.documents` explicitly rejects non-ARM64. API/web image success does not cover these runtimes. Next: acquire and checksum-pin the matching Debian amd64 archives through signed APT, parameterize the offline bundles without relaxing validation, and run video/document acceptance in amd64 containers before packaging the trusted worker host. Do not transfer local ARM64 images to Railway and assume they run natively.
