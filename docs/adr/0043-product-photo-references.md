# 0043 — Private uploaded product photos and approved reference crops

Reuse the existing private upload, malware scan and durable validation activity. After a PNG/JPEG/WebP passes the checks, the worker creates an orientation-corrected JPEG no larger than 3072 pixels per side and 6 MiB, flattening transparency onto white and removing metadata. The original download remains byte-identical. Immutable `uploaded_visuals` records preserve original and normalized checksums, dimensions, source asset and job. Only a ready source is visible through the scoped customer API; worker reads are restricted to its validation job or the exact selected creative references. Upload allowance reserves an additional 6 MiB per image for this derivative, under the existing daily/business limits.

A private image upload is not provider consent. Users inspect the normalized photo, optionally choose a crop, name it and approve reuse. Approval persists an immutable source reference and crop rectangle; altering a crop requires removing the existing approval first. Square/portrait/landscape presets and optional position/size adjustments share a private checksum-verified browser preview. Preview drawing is local; only the durable worker determines provider input pixels. The existing maximum of three selected references and 30 active approved references applies.

Creative jobs verify the normalized source checksum and dimensions, apply the approved crop, convert to bounded PNG and pass the actual pixels through the existing official image-edit adapter. The output manifest retains source identity/hash, exact crop and provider-input hash. Reference revocation still blocks new provider submissions and preserves prior history. Cropping or reference approval never substitutes for video prompt approval or final creative/publication review.

Existing ready uploads from before migration 037 do not gain derivatives retroactively; they can be re-uploaded through the checked path. Product photos feed the static creative pipeline. Higgsfield continues to require an approved canonical creative image through its existing consent-bound lease workflow; arbitrary uploaded photos are not silently published to a video provider.

Tests cover actual scanning/storage/workflow recovery, normalized dimensions and metadata removal, source/consent/crop/tenant checks, reserved derivative capacity, uploaded-reference pixels in MOCK OpenAI multipart calls, immutable crop provenance, revocation/corruption rejection and the customer upload/crop/approval browser flow. No live model fidelity or cloud deployment is claimed.
