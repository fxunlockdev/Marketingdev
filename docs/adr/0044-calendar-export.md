# 0044 — Saved content calendar exports

The authenticated business calendar service exposes CSV and iCalendar snapshots using the same date, channel, state and plan filters as the existing calendar query. Export requests do not approve, schedule or publish posts. The scoped SQL reads up to 10,000 saved rows in one ordered query rather than silently exporting only the first 100-row page; oversized results fail. Standard business resolution and forced RLS remain in force. No schema or provider integration changes.

CSV includes the exact planned UTC time, original plan timezone, saved revision, channel, format, review state, hook, brief and caption. Fields are quoted and formula prefixes are neutralized. iCalendar escapes untrusted text, folds by UTF-8 octet length, retains stable per-slot UID and revision, and uses UTC instants to avoid daylight-saving ambiguity. Events are tentative, or canceled when the saved slot is canceled; final publication state is not inferred. Both formats describe a planning snapshot, not an automatically synchronized subscription. No media URLs or credentials are exported.

Content Plan downloads all matching rows for the displayed period/channel/state, including further result pages. Its browser test imports the actual response into a downloaded file and checks all 30 saved events. Service tests cover 101 rows, unauthenticated and foreign-business denial, sibling isolation, channel filtering and invalid formats. Contract tests cover spreadsheet formulas, quoted/multiline text, UTF-8 folding, event injection and stable time/revision identity. Deployment/live acceptance remains separate.
