### Saved carousel downloads

The authenticated version download streams a ZIP using STORE (PNG media is already compressed). It snapshots the exact saved composition, verifies its fingerprint, rechecks business access before every private object read, and verifies each PNG's size and SHA-256. Only one slide is read at a time; the archive permits at most ten 20 MiB slides plus bounded caption/manifest entries. Fixed filenames preserve order without incorporating user paths. No provider call or new rendering occurs. This is a read of existing media, not a new generation job.

The manifest contains the composition fingerprint, immutable creative/export IDs, per-slide hashes and alt text, shared caption/channel, and approval/currentness at download time. It excludes private object keys and signed URLs. Historic saved versions are downloadable and explicitly identified as not current; downloading never approves or schedules content. Errors abort the stream; the browser checks its expected byte length before offering a file. Publishing remains a separate permission- and approval-gated workflow.
